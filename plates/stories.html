How submissions work

  1. Suggest: the button opens a short form on GitHub (a free GitHub account is required). It asks for a title, theme, the story, dataset links and sources.
  2. Review: an editor checks the links and sources, and may follow up in the discussion thread.
  3. Publish: accepted stories are added to stories.csv and appear here, credited as you choose.

Suggestions are public. Please don't include personal contact details or non-public information.
